データ削除の手順

トッププライバシーポリシー

本ツールは、投稿した人を特定できる情報（ユーザー名・ユーザー ID・投稿の URL）を保存しません。そのため、通常は個人を指定して削除できるデータを持っていません。

  1. 削除を希望する投稿の本文（またはその一部）を添えて、kfkfkf.0120@gmail.com までご連絡ください。
  2. 7日以内に、該当する本文を削除し、結果をお知らせします。
  3. Threads でログインして本ツールを使った方は、Threads の「設定」→「アカウント」→「ウェブサイトのアクセス許可」で pain-to-product を削除すると、連携が解除されます。

なお、投稿の本文はすべて取得から30日で自動的に削除されます。

Data deletion instructions (English)

This tool does not store information that identifies the author of a post (usernames, user IDs or post URLs), so we normally hold no data that can be deleted for a specific person.

  1. Email kfkfkf.0120@gmail.com with the text (or part of the text) of the post you want deleted.
  2. We will delete the matching text within 7 days and let you know the result.
  3. If you used this tool by logging in with Threads, you can remove the connection in Threads under Settings > Account > Website permissions.

All post text is automatically deleted 30 days after collection.
